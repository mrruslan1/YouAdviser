# YouAdviser

**Персональный Telegram-помощник для общения, профориентации и знакомства с профессиями.**  
*Your career starts with the right choice.*

YouAdviser — Telegram-бот на Python. Он объединяет свободный диалог с ИИ и инструменты для изучения карьерных направлений: опрос, каталог профессий, персональные рекомендации, карточки профессий, сравнение и планы первых шагов.

> Важно: YouAdviser помогает исследовать варианты, но не является профессиональной психологической диагностикой. Рекомендации ИИ могут быть неточными. Условия поступления, зарплаты, требования работодателей и перспективы рынка труда зависят от страны и времени и должны проверяться по актуальным источникам.

## Возможности

### Свободное общение с ИИ

- Режим «Поговорить» принимает обычные текстовые сообщения и не ограничивает разговор только темой профессий.
- Можно задавать вопросы, просить объяснить тему, написать или разобрать код, подготовить текст, придумать идеи или помочь с планированием.
- Бот передаёт модели историю последних сообщений и подходящие сохранённые сведения о пользователе, чтобы учитывать контекст беседы.
- При запросе на программирование бот старается соблюдать заданные требования к языку, стилю, формату, комментариям и оформлению кода.
- Код формируется как отдельный блок, а длинные ответы отправляются несколькими сообщениями. **Бот не запускает и не тестирует сгенерированный код автоматически** — результат нужно проверить самостоятельно.

Свободная генерация ответов требует действующего `GROQ_API_KEY`. Без него доступны локальные функции каталога и профориентации, но полноценный ИИ-диалог, генерация кода и анализ изображений недоступны.

### Работа с фотографиями

Пользователь может отправить фотографию, при необходимости добавив к ней текстовый вопрос. При настроенном Groq API бот передаёт изображение vision-модели и отправляет полученный текстовый ответ. Например, можно попросить прочитать текст на снимке или объяснить изображённое задание. Размер фотографии ограничен обработчиком бота.

### Профориентация и каталог

- **Опрос из четырёх шагов:** имя или никнейм (можно пропустить), интересы, сильные стороны и предпочтительный формат работы.
- **Каталог из 766 уникальных профессий.** Данные хранятся в `professions.json` и загружаются в SQLite при запуске.
- **Семь направлений каталога:** IT и технологии; дизайн и творчество; наука и инженерия; люди и помощь; бизнес и управление; медиа и коммуникации; практические профессии.
- **Подбор профессий:** сначала локальный алгоритм оценивает совпадения по названию, описанию, интересам, навыкам и тегам. При подключённом Groq ИИ дополнительно ранжирует кандидатов из каталога. Бот не должен придумывать профессии вне переданного списка.
- **Карточки профессий:** краткое описание, полезные навыки, связанные интересы, формат работы, идеи для обучения и небольшое практическое действие.
- **Тематические эмодзи:** значки подбираются по типу профессии. Набор определяется названием профессии, поэтому оформление карточек обычно отличается.
- **Избранное:** пользователь может сохранять карточки и удалять их из списка.
- **План первых шагов:** предлагает примерный способ познакомиться с выбранной профессией.
- **Сравнение:** сопоставляет две профессии по сведениям каталога; при подключённом ИИ может сформировать дополнительное текстовое сравнение.
- **Случайная профессия:** показывает случайную карточку из каталога.
- **Профиль:** хранит ответы пользователя из профориентационного опроса.

Локальный подбор основан на данных каталога и совпадениях слов/их форм, а не на отдельной обученной модели. ИИ-ранжирование улучшает семантическое сопоставление, но не гарантирует объективный или единственно правильный выбор профессии.

### История и долговременная память

- Сообщения диалога сохраняются в базе данных; в запрос к ИИ включается ограниченный фрагмент истории.
- Пользователь может явно добавить факт в память через `/remember` или фразу «Запомни ...».
- При подключённом Groq бот периодически пытается выделять полезные несекретные сведения из беседы для будущей персонализации.
- Просмотреть и удалить долговременную память можно отдельно от истории переписки.

### Панель владельца

При заданном `OWNER_TELEGRAM_ID` владелец может открыть `/admin`. В панели доступны дополнительные инструкции для шести режимов (общение, профориентация, рекомендации, анализ фото, планы и сравнение), выбор ID модели Groq и сброс этих настроек. Панель ограничена Telegram ID владельца.

## Технологии

| Технология | Использование в проекте |
|---|---|
| Python 3.10+ | Основной язык проекта |
| aiogram 3 | Telegram Bot API и обработчики сообщений |
| SQLAlchemy 2 (asyncio) | Асинхронная работа с базой данных |
| SQLite + aiosqlite | Хранение каталога, профилей, избранного, истории и памяти по умолчанию |
| Groq API | Генерация ответов, ИИ-подбор, планы, сравнение и анализ изображений |
| httpx | Асинхронные HTTP-запросы к Groq API |
| python-dotenv | Чтение конфигурации из `.env` |
| JSON | Каталог профессий и дополнительные настройки ИИ |

Проект использует Groq API с совместимым с OpenAI форматом Chat Completions. Для работы с Groq отдельная библиотека OpenAI SDK не требуется.

## Установка и запуск

### 1. Требования

- Python 3.10 или новее.
- Telegram-бот, созданный через [@BotFather](https://t.me/BotFather).
- Ключ Groq API из [Groq Console](https://console.groq.com/keys) — нужен для полноценного ИИ-режима, генерации кода, анализа фотографий и ИИ-улучшения рекомендаций.

### 2. Скачайте проект и установите зависимости

Откройте терминал в папке проекта:

```bash
python -m venv .venv
```

Windows (PowerShell):

```powershell
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

macOS / Linux:

```bash
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

### 3. Настройте переменные окружения

Создайте файл `.env` в корневой папке проекта, скопировав `.env.example`, и заполните значения:

```env
BOT_TOKEN=YOUR_TELEGRAM_BOT_TOKEN
OWNER_TELEGRAM_ID=
DATABASE_URL=sqlite+aiosqlite:///careerguide.db
GROQ_API_KEY=YOUR_GROQ_API_KEY
GROQ_MODEL=openai/gpt-oss-120b
GROQ_REASONING_EFFORT=high
GROQ_MAX_COMPLETION_TOKENS=8192
GROQ_VISION_MODEL=qwen/qwen3.8-27b
```

Пояснения:

- `BOT_TOKEN` — токен Telegram-бота от BotFather; обязателен.
- `OWNER_TELEGRAM_ID` — необязательный числовой Telegram ID владельца. Его можно узнать командой `/myid` после запуска; значение нужно добавить в `.env` и перезапустить бота, чтобы пользоваться `/admin`.
- `DATABASE_URL` — URL базы данных. По умолчанию используется локальная SQLite-база `careerguide.db`.
- `GROQ_API_KEY` — секретный ключ Groq. Без него полноценная генерация ответов и кода, анализ фото и ИИ-ранжирование не работают.
- `GROQ_MODEL` — модель для обычного диалога и текстовых задач; значение по умолчанию в шаблоне — `openai/gpt-oss-120b`.
- `GROQ_REASONING_EFFORT` — уровень рассуждений для моделей GPT-OSS (`low`, `medium` или `high`).
- `GROQ_MAX_COMPLETION_TOKENS` — запрошенный лимит токенов ответа; код ограничивает его диапазоном от 1024 до 32768.
- `GROQ_VISION_MODEL` — модель для обработки изображений; шаблон задаёт `qwen/qwen3.8-27b`.

Названия моделей и доступность API зависят от Groq и могут меняться. При необходимости выберите доступную вашему аккаунту модель в `.env` или в панели владельца.

**Никогда не публикуйте `.env`, токен Telegram, ключ Groq или базу с реальными данными пользователей.** Файл `.env` и локальные базы данных исключены из Git через `.gitignore`. Если секрет уже попал в публичный репозиторий, отзовите или замените его у соответствующего провайдера.

### 4. Запустите бота

```bash
python main.py
```

Откройте своего бота в Telegram и отправьте `/start`. При первом запуске проект создаст таблицы SQLite и синхронизирует каталог из `professions.json`. При последующих запусках отсутствующие профессии будут добавлены, а поля существующих карточек будут обновлены по JSON-файлу.

Для остановки нажмите `Ctrl + C` в терминале.

## Данные и база данных

По умолчанию используется файл `careerguide.db`. Таблицы создаются автоматически при первом запуске.

| Таблица | Что хранит |
|---|---|
| `professions` | Каталог: название, описание, навыки, интересы, формат работы, сведения о начале обучения и поисковые теги |
| `user_profiles` | Telegram ID, имя/никнейм, интересы, сильные стороны, предпочитаемый формат работы и дата обновления профиля |
| `favorites` | Связь пользователя с сохранённой профессией |
| `chat_messages` | Историю сообщений с ролью отправителя и временем сохранения |
| `user_memories` | Отдельные факты, сохранённые для персонализации будущих ответов |
| `ai_settings` | Таблица настроек ИИ, объявленная в моделях базы; текущая панель владельца фактически сохраняет настройки в `ai_settings.json` |

Навыки и интересы профессий хранятся как JSON-массивы в текстовых полях таблицы `professions`. Отдельных таблиц `skills`, `categories`, `tests`, `universities` или `courses` в текущей реализации нет. Ответы опроса сохраняются в `user_profiles`; отдельная таблица с результатами тестов не используется.

### Формат `professions.json`

Файл `professions.json` — основной источник каталога. Он содержит список объектов со следующими полями:

| Поле | Формат | Значение |
|---|---|---|
| `title` | Строка | Название профессии |
| `description` | Строка | Описание работы |
| `skills` | Массив строк | Полезные навыки и качества |
| `interests` | Массив строк | Связанные интересы |
| `work_style` | Строка | Предпочтительный формат работы |
| `education` | Строка | Идеи для знакомства с направлением и обучения |
| `tags` | Строка | Поисковые слова и метки категории |

Чтобы добавить профессию, внесите в JSON новый объект с заполненными полями. При следующем запуске бот синхронизирует его с SQLite. Если вручную менять описательные данные профессии только в базе, при следующем запуске они будут заменены значениями из `professions.json`.

## Настройки ИИ

Файл `ai_settings.json` хранит локальное переопределение модели и дополнительные инструкции для режимов `chat`, `career`, `recommendations`, `photo`, `plan` и `compare`. Эти настройки также можно менять через `/admin`, если задан `OWNER_TELEGRAM_ID`.

API-ключи и Telegram-токен в `ai_settings.json` хранить нельзя — для секретов предназначен локальный `.env`.

## Ограничения текущей версии

- Без `GROQ_API_KEY` бот не может вести полноценный свободный ИИ-диалог, генерировать произвольный код, анализировать фотографии или выполнять ИИ-ранжирование. Локальный каталог и базовый подбор по совпадениям остаются доступны.
- Бот не запускает сгенерированные программы и не гарантирует отсутствие ошибок в ответах ИИ.
- Встроенный каталог не содержит актуальных зарплат, вакансий, данных о поступлении, рейтингов учебных заведений или подключённого поиска курсов.
- Планы и сравнения — ориентировочные материалы для знакомства с направлениями, а не гарантия трудоустройства или карьерного результата.
- Состояния текущих многошаговых действий хранятся в памяти процесса; после перезапуска бота незавершённый опрос или действие может потребоваться начать заново.

## Безопасность и публикация на GitHub

1. Заполните секреты только в локальном `.env`, созданном из `.env.example`.
2. Проверьте, что `.env`, `careerguide.db`, другие файлы SQLite, виртуальное окружение, логи и кэш не попадают в коммит.
3. Не загружайте в публичный репозиторий историю переписки, профили, Telegram ID пользователей и резервные копии рабочей базы.
4. Не публикуйте ключи в README, исходном коде, скриншотах и сообщениях коммитов.
5. Перед открытием репозитория проверьте состав коммита и следуйте правилам из [SECURITY.md](SECURITY.md).
