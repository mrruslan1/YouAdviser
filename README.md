💡 О проекте
> YouAdviser — молодой технологический стартап, представляющий собой интеллектуального Telegram-бота для помощи в выборе профессии и построении карьерного пути.
Бот анализирует интересы, навыки и предпочтения пользователей, предоставляя персонализированные рекомендации и помогая определить подходящее профессиональное направление.
Наша миссия — сделать выбор будущей профессии простым, понятным и доступным каждому.

----------------------------------------------------------------

🤖 Интеллектуальный помощник

Ответы на вопросы о профессиях и карьере.
Персонализированные рекомендации.

**🔄 Как работает бот?**
Пользователь запускает Telegram-бота.
Выбирает раздел меню или отправляет сообщение.
Бот анализирует запрос и интересы пользователя.
При необходимости получает информацию из базы данных.
Формирует персонализированный ответ.
Пользователь получает рекомендации и может сохранить понравившиеся профессии.
